# Mill Pond Research

**AI infrastructure for organizations that want options.**

We build [Xilos](https://xilos.ai) — the open-source AI gateway for routing, governance, caching, and cost control. Point your agents at Xilos with one `base_url` change and get multi-model routing, guardrails, semantic caching, and full audit trails.

## Projects

| Project | Description |
|---------|-------------|
| [xilos-oss](https://github.com/Mill-Pond-Research/xilos-oss) | Open-source AI gateway. Solo (single user) and Org (team) modes. Self-host anywhere. |
| [docs-xilos](https://github.com/Mill-Pond-Research/docs-xilos) | Documentation for Xilos — docs.xilos.ai |
| [Xilos WorkBench](https://github.com/Mill-Pond-Research/xilos-workbench) | AI-native workspace built on Xilos. Docs, spreadsheets, presentations, agents. |
| [xilos-python-sdk](https://github.com/Mill-Pond-Research/xilos-python-sdk) | Python SDK for the Xilos API. |
